🔧 Setup Environment

cd your/project/folder
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install pandas openpyxl pywin32

✨ Create and activate your virtual environment, then install the required libraries.

📂 Excel File Preparation

Email, Subject, Body
test@example.com, Follow-Up Reminder, Hello [FirstName], please review the details...

📑 Keep your Excel file in the reference folder. Add columns Email, Subject, and Body. Optionally, add AttachmentPath for files.

▶️ Run the Program

python main.py

🚀 Activate your environment and run the script. Outlook will send emails using the details from Excel.

🪄 Wizard Notes

✔️ Outlook must be installed and configured.
✔️ pywin32 handles Outlook automation.
✔️ Works only on Windows.
✔️ Personalize Body with placeholders like [FirstName].
